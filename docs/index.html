Your notes, encrypted
on every device.

File Vault keeps password-protected vaults of notes in sync between Windows and Android. Everything is encrypted on your device before it is uploaded.

Download View source
Windows Android Open source

AES-256-GCM encryption

Every file is encrypted with its own salt and nonce, using a key derived from your vault password.

Synced across devices

Sign in on Windows and Android to get the same vaults everywhere, with edit conflict detection.

Zero knowledge

Vault passwords never leave your device. The server only ever stores ciphertext.

Encrypted backups

Export vaults to encrypted ZIP files you can safely keep in OneDrive or anywhere else.
